# voice-check
1. Load the Voice sections of every character in scope.
2. Extract each character's dialogue lines from the chapters. Test: with tags removed, could you tell who is speaking?
3. Report in `feedback/YYYY-MM-DD-voice-<model>-<scope>.md`: lines that could belong to anyone, lines out of character (cite the character file), and one rewritten example per problem showing the character's voice.
4. Suggest additions to character Voice sections when the prose has established new patterns.
5. Follow the feedback protocol in AGENTS.md. Don't edit the manuscript. Commit with `--pass voice-check`.
